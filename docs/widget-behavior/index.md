## 已确认方向

- 当前只记录视频观看行为与必要数据，不提供关闭记录功能；不记录展开、最小化或 Canvas 操作。canvasId 仍作为归属上下文保留。
- 不实施行为偏好推断或 workflow 个性化；对话继续使用已有 Mastra 记录。
- 未来偏好持久化复用 Mastra Working Memory，不建设平行的 Memory 引擎。
- 卡片类型声明领域行为，实例化时绑定记录策略；公共记录层不按卡片类型分支。
- 公共运行时注入 Canvas、实例、身份及因果上下文，支持未来分析特定 workflow 的 Canvas 偏好。
- Canvas 身份独立于会话，历史保留行为发生时的归属。
