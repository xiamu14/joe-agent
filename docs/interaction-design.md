# /joe 交互设计

## 设计方向

- 即时语音为主，文本对话为辅。
- 参考 visionOS 的空间和磨砂材质，采用 light 模式、白色 semibold 文本和浅亮边缘高光。
- 玻璃材质不添加固定色相，随固定背景透出颜色；以用户提供的 Video.js 控制条截图为材质参考，使用中性半透明底、背景模糊、柔和边缘高光与阴影。参考页面：https://videojs.org/ 。
- 使用用户提供的固定图片背景，居中铺满屏幕。
- 已读取 [Vision OS Design System 社区文件](https://www.figma.com/design/mbOyXTPKKtQj5vhQwFqdhH/Vision-OS-Design-System--Community-?node-id=2-6772) 的卡片、窗口控制和媒体控制条。采用其 40px 卡片圆角、50px 背景模糊和顶部内高光；控制条参考 40px 模糊的胶囊轮廓，具体布局按本文交互规则调整。

## 已确认的交互规则

- 首次启用并授权后，在 /joe 页面内持续接听；卡片关闭、切换和进入沉浸层不停止接听。支持直接说话打断 Joe，对话卡片内提供当前静音／恢复入口；关闭卡片不改变用户主动设定的静音状态。
- 设置卡片提供“默认静音”开关，默认关闭；每次进入 /joe 时读取该偏好，决定是否接听。对话卡片内的静音／恢复只影响当前使用，不修改默认设置。
- “静音”仅暂停麦克风输入，不影响 Joe 的语音回复；回复播报由现有独立的语音输出设置控制，支持输入静音时通过文本提问并听取回答。
- 首次访问 /joe 时自动弹出语音启用卡片询问；用户确认后申请浏览器麦克风授权，并解锁语音播放。
- 首次语音启用卡片为临时弹层，覆盖默认的主对话卡片与次费用卡片，不占普通卡片位置；完成或跳过后露出默认布局。
- 首次暂不启用或授权失败时，关闭询问卡片并允许继续文本对话；小球表达未接听／故障状态，对话卡片内提供重试入口，不反复弹窗。
- 底部不增加独立麦克风按钮；沿用 Joe 现有 3D 小球动效表达情绪，以及连接中、接听中、故障等交互状态。
- 对话卡片顶部保留适当缩小的 3D 情绪球，作为 Joe 情绪可视化部件；对话卡片为主卡片时，底部常驻小球切为静态图，避免重复 3D 渲染带来的 GPU 消耗。
- 对话卡片退为次卡片或隐藏时，卡片内小球静止，底部小球恢复 3D 动效；同一时刻只运行一处 3D 小球，静止处停止持续渲染。
- 对话卡片底部始终保留可编辑的文本输入框；语音转写单独呈现，不写入文本草稿。开始打字不关闭麦克风，发送文本可打断 Joe 当前回答并处理文本消息。
- 保留翻译能力，不以语音与原始回答必须一致为约束，不移除翻译路径。
- 内容相同时只显示一份；存在不同语言内容时，每条消息提供独立的译文展开／收起入口，不使用对话级统一显示开关，展开不改变主对话或播报语言。
- 支持英语学习场景：主对话持续使用英文展示与英文播报，用户可查看辅助译文理解内容；不能仅为了查看辅助译文而切换主对话或播报语言。
- 语言配置沿用现有设置，不新增独立的“译文语言”设置。
- 同时最多显示一张普通卡片和一张对话卡片。
- 默认展示对话卡片为主、费用信息卡片为次。
- 主卡片居中，次卡片位于右侧、倾斜展示，宽度缩至该卡片允许的最小值。
- 点击次卡片或左右滑动可交换主次；对话卡片也遵循同一规则，交换不影响持续接听。
- 次卡片保留内容预览，首版禁止内部具体操作，只保留切为主卡片的交互；后续按具体卡片逐项开放操作。
- 对话卡片为主卡片时不允许关闭，不显示关闭入口；关闭操作导致所有卡片均关闭时，自动打开对话卡片作为主卡片，避免空白画面。
- AI 根据表达需要决定是否唤起卡片。简单天气可语音回答；多日天气、日出日落等需要浏览比较的信息可唤起天气卡片。
- 新普通卡片替换当前普通卡片；退场卡片保留内容状态和阅读位置，可从卡片总览恢复。
- 关闭替代卡片不自动恢复上一张普通卡片；保留仍打开的卡片，没有剩余卡片时按规则自动打开对话卡片。
- 沉浸展示期间也由 AI 判断信息展示密度：低密度内容直接语音回答，保留当前沉浸画面；需要卡片承载的高密度内容才退出沉浸层、让原卡片退场，以新普通卡片为主，已打开的对话卡片为次。
- 沉浸层中底部常驻控制条仍完整可见、可操作，位于沉浸内容上方；其底部区域铺设渐变模糊，遮住下层卡片，小球的接听状态始终可见。
- 卡片总览为临时选择层，覆盖当前卡片但不使其退场，不占用普通卡片位置；缩略图平铺，可纵向滚动，底部控制条保持可用。
- 点击总览空白处或再次点击总览按钮关闭总览，回到原画面；选中卡片后关闭总览，将所选卡片置为主卡片，并遵守普通卡片与对话卡片的数量限制。
- 宽屏采用居中主卡片与右侧倾斜次卡片；窄屏一次仅展示主卡片，另一张保留，可通过左右滑动切换或从卡片总览选择。底部控制条保持完整可见、可操作，语音持续接听。
- 底部常驻控制条从左至右为时间入口、卡片总览入口、Joe 小球；分别打开时间卡片、卡片总览和对话卡片。

## 首版卡片范围

- 对话卡片。
- 费用卡片：沿用现有模型今日／累计费用，以及语音账户余额或账单。
- 时间卡片：时间、当前天气、累计在线时间。
- 设置卡片：沿用现有模型、语音等设置。

背景固定使用提供的图片，不提供背景切换或图片上传。

文章、视频卡片留待后续；多日天气与日出日落需要补充天气数据能力。
首版不开放沉浸层，不显示“完全展开”按钮；沉浸层随后续文章、视频等适用卡片一起实现。

## 后续细化

- 后续沉浸层的进入条件及退出后原主次位置的恢复规则。
- 卡片尺寸、倾斜角度、玻璃材质参数与动画节奏，在视觉实现中验证。
- 普通卡片自身 modal 的规则随具体卡片功能确定，首版不增加通用 modal 能力。
