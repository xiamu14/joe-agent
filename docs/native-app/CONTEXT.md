# 原生桌面交互空间

本词汇表用于新的原生桌面方案；根目录词汇表保留为现有 Web 版本的记录。

## Language

**内容卡片**：
在 Joe 对话空间中承载视频、网页等内容的展示单元，可由用户语音请求唤起。
_Avoid_：独立应用窗口

**固定内容卡片**：
内容来源预先指定、仍可真实使用的内容卡片；本轮指指定的 YouTube 视频与 X 首页。
_Avoid_：静态模型、模拟播放

**卡片退场**：
内容卡片离开当前画面，但在本次 App 运行期间保留浏览位置或播放进度；视频退场时暂停，恢复展示不自动恢复播放。
_Avoid_：销毁卡片、重置内容

**堆叠**：
多张内容卡片以前后层次同时保留的展示方式；后方卡片仍在场，不属于退场。
_Avoid_：卡片退场

**并列**：
多张内容卡片展开排列、供同时观看或对照的展示方式。
_Avoid_：独立多窗口

**沉浸**：
一张内容卡片占据主要展示空间的状态；底部保留小型 Orb 与输入按钮组，对话记录暂时隐藏并在退出后恢复。
_Avoid_：隐藏全部控制

**持续接听**：
用户授权并启用麦克风后，无需逐次点击即可说话的状态；卡片切换、退场与沉浸不结束接听。
_Avoid_：按次录音、唤醒词模式

**输入静音**：
暂停麦克风输入的状态，不影响 Joe 的语音回复。
_Avoid_：全部静音

**临时暂停**：
为用户语音输入及本轮交流而暂时停止视频播放的状态；交流结束后仅在原本播放、卡片仍在场且没有更新的暂停意图时恢复。
_Avoid_：卡片退场、用户主动暂停

**连续对话**：
用户按时间延续与 Joe 的交流，不因底层上下文分段而开始一段新的可见聊天。
_Avoid_：无限上下文、永久记住全部历史

**上下文分段（thread）**：
连续对话中供模型处理的一段上下文，不是独立的 App 窗口或用户必须管理的聊天入口。
_Avoid_：桌面窗口、新聊天

**交接**：
将当前目标、关键事实与未完成事项传递给下一个上下文分段，使用户继续同一段交流。
_Avoid_：打开新窗口、清空对话
